# 上游 v1.6.0 同步后的评审修复

2026-10-21，基于 `91d6e43`，修复本轮评审指出的五项桌面集成问题。保持现有 WPF / .NET 10、草稿保存冲突检查、三协议客户端及更新通道，不修改版本号或既有发布附件。

| 问题 | 修复后的行为 |
|---|---|
| 离开更新页仍保留自动重启意图 | 只有设置窗口可见、未最小化且选中通用/更新页时才观看更新；切页、隐藏、最小化或关闭会撤销安装意图。返回不会恢复意图，持续观看时仍只需确认一次。 |
| 动作试运行使用窗口打开时的配置 | 使用当前已保存的模型配置、密钥和语言；配置重载会刷新试运行门禁与参照过期状态。本地草稿不发送，外部修改后的保存冲突仍阻止覆盖；动作本身被外部修改时提示重开设置，避免试运行与显示的提示词不一致。 |
| 提示词变更后面板仍被旧失败挡住 | 请求开始时保存动作提示词；当前提示词改变后，旧失败视为上一次请求，可执行新请求。还原原提示词会恢复原失败的门禁。 |
| 单段原处翻译漏接自动分段 | `LayerSession` 的单段分支使用现有 `SendRecoveringLengthAsync`；显式长度拒绝后按序分段，结果合并后进入原有缓存路径。普通错误与取消仍沿用现有处理。 |
| 配置助手缺少最近连接检查 | 交接使用匹配当前配置指纹的最近检查记录。界面检查匹配已保存配置时持久化；未保存草稿的检查留在窗口内，指纹变为当前配置后才用于诊断；取消不覆盖任何检查证据。 |

## 定向回归的证据范围

`tests/Cida.VisualChecks/SyncRecoveryChecks.cs` 使用真实 WPF 设置/面板和真实桌面调用路径，配合内存配置及环回 HTTP 服务：

1. 更新：构造但未显示的窗口与模型页不观看更新；切页、隐藏/重显、最小化/还原、关闭均撤销安装意图；返回不恢复意图；持续观看时下载完成仍请求安装。
2. 试运行：模拟配置拒绝后，通过 `ReloadSettings()` 加载修复后的配置，当前窗口即可重试；检查实际请求的模型与合成密钥；未保存提示词不发送，外部配置变化后的保存冲突检查仍有效。
3. 面板：未改变的配置失败禁止提交；只修改提示词即可执行；还原提示词再次禁止提交。
4. 段落翻译：直接执行真实 `LayerSession` 单段发送分支；完整原文被 HTTP 413 拒绝后分段，完整有序结果进入缓存，整段原文只发送一次。不启动 UIA 轮询或放置覆盖层。
5. 配置交接：当前失败检查进入说明，旧指纹被过滤；界面连接检查持久化并进入说明；草稿检查不覆盖已保存配置的证据，匹配后才使用；取消保留旧记录并显示已取消。

结果文件位于检查工具输出目录下的 `inspection-profile/sync-recovery/result.json`；失败时以非零退出码及同目录 `error.txt` 报告。每次运行先清除这两个精确输出文件，避免混用旧结果。

这些检查不读取用户配置、注册用户快捷键、修改剪贴板、调用外部模型或安装更新。不重新执行全量视觉截图、打包或发布；真实应用的 UIA/Alt+D 交互、远端更新下载与安装重启、干净机器升级仍不在本次验证结论中。
