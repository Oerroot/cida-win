# 辞达 Cida Windows v0.2.0-rc.2（未签名候选版）

完整重构 Windows 体验：800 DIP 主面板、独立滚动的原文与纸色结果区、随系统浅深色、中英文阅读字体；四页设置、自定义动作、草稿连接测试及预览、热键录入、配置恢复与更新入口。

新增 Alt+F 改进并替换，验证来源/选区/文档后才粘贴，并回读核对。OCR 随包提供简繁中文、英文模型与原生运行库，无需开发证书或身份包。段落与整窗覆盖层使用真实 UIA 文本范围，跟随滚动并拒绝失效结果，译文过长转入面板。单实例、键盘交互、原子配置写入、DPAPI 密钥保存与候选更新通道同时落地。

## 下载

- `Cida-win-x64-preview-Setup.exe`：Windows x64 安装包。
- `Cida-win-x64-preview-Portable.zip`：完整解压，运行根目录 `辞达 Cida（候选版）.exe`。
- CLI 位于安装或便携目录的 `current/Cida.Cli.exe`。
- `SHA256SUMS.txt`：附件校验；full nupkg、RELEASES 与 JSON 文件供更新程序使用。

GUI / CLI 为自包含 .NET 10；OCR 语言资源与 VC runtime 应用本地部署。没有安装开发证书、修改证书信任或注册身份包的启动步骤。已安装旧版本可运行新 Setup 手动升级；旧 tag 保留，配置沿用当前用户目录。

## 验证

Windows 11 x64 本机 Release 构建 0 错误、0 警告；96 项 Core 与 5 项 Windows 测试通过。Windows 测试包含中英文离线 OCR、配置损坏恢复/密钥加密、选区替换与一次撤销、剪贴板恢复、UIA 段落范围/滚动、单段缓存复用及整窗原文切换。真实 WPF 窗口键盘、动作新增/排序/预览/保存已执行；26 张真实产品视图受控渲染覆盖浅深色和关键状态。

全部条件及可复现命令见仓库 `docs/windows-experience-verification.md`。模拟响应仅用于验证交互，不代表外部服务或所有来源应用已经验收。

## 候选边界

Setup 和应用可执行文件尚无受信任 Authenticode 签名；这是用户确认交付的候选包。完整中文 IME 候选交互、外部应用兼容矩阵、实际混合 DPI 多屏、干净机器安装/升级/卸载和实际远端自动更新闭环尚需目标环境验收。受控 1/1.25/1.5/2 倍渲染不等于实际 OS DPI 测试。

不把此版本标为正式签名发行版。没有账户、云同步或持久翻译历史。

RC.1 的发布流水线在新 Visual Studio runner 上因运行库目录名称变化而停止，未发布附件。RC.2 按必需 DLL 查找 x64 VC redist，并继续核验所有 Microsoft 签名；旧 tag 不改写。
