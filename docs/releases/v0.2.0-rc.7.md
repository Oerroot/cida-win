- 失败恢复：请求失败时保留已经输出的文字，并提供重试或模型设置入口；配置类失败把诊断交给 AI 配置助手，配置未变时不重复发送。
- 超长原文：模型返回显式长度限制时自动分段处理，逐段流式拼接或组装为单个结果；编号层翻译保留段落 id 与占位符，不需要手动缩短原文。
- 动作试运行：动作保存后可直接用固定样例试运行；编辑时保留上次完整结果作参照，也可以放弃修改；保存成功但试运行失败时分别说明状态。
- 快捷键与能力说明：快捷键页逐条解释每个入口的用途，长组合保持可读；补充 UI Automation 读取/替换、离线 OCR 与全局热键冲突的说明。
- 一次确认安装更新：确认「安装并重启」后开始下载；仍在更新页时下载完成自动重启，离开后继续下载但不自动重启，可稍后再安装，也可跳过这个版本。重新检查不会显示上次失败时的旧版本信息。
- 文字易读性：设置说明、语言确认和其他重要小字使用更易读的次级文字，并增加三级文字层级；字号、品牌与焦点样式保持。
