# 辞达 Cida Windows v0.1.3（预发布）

本版本修复评审发现的 15 项问题，提供 Windows x64 安装版和便携版。GUI 与 CLI 自包含，无需另装 .NET。

## 下载与运行

- 安装版：下载 `Cida-win-x64-Setup.exe` 并运行。
- 便携版：下载 `Cida-win-x64-Portable.zip`，完整解压后运行根目录的 `辞达 Cida.exe`。
- 控制台命令：在安装目录或便携版 `current` 目录使用 `Cida.Cli.exe`。
- `SHA256SUMS.txt` 用于校验附件；nupkg 与 JSON/RELEASES 文件供更新工具使用，普通用户选择 Setup 或 Portable 即可。

## 修复与验证

修复鉴权头、取词源窗口、Ctrl+C 原生结构、整窗快捷键、DPI 坐标、请求取消与超时、快捷键禁用持久化、覆盖层还原、设置检查、UIA 焦点与剪贴板恢复。移除输入/IME 正文日志，分发包移除签名私钥，补齐 CLI 和自包含运行时。

本机 Windows x64 Release 构建：0 错误、0 警告；Core 85/85、受控 Windows 桌面测试 2/2 通过。实际便携包的 GUI/CLI 命令冒烟与私钥扫描通过。详细范围和测试条件见仓库 `docs/review-fixes.md`；本次发布附 `verification.json` 及测试记录。

## 预发布边界

安装程序尚无正式 Authenticode 签名，身份 MSIX 使用开发证书，目标机器的包身份注册取决于签名信任；OCR 还依赖相应系统语言包。跨应用兼容性、完整中文 IME、混合 DPI 多屏及干净机器安装/升级/卸载仍待人工验收。

本版本不代表上述人工验收或正式发布完成；历史 Git 提交中的旧私钥副本与旧证书信任尚未清理。
