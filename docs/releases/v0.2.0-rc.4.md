# 辞达 Cida Windows v0.2.0-rc.4（未签名候选版）

修复主面板渲染和拖动，并重做设置页折叠控件：

- 主面板改为不透明原生窗口，统一界面字体、文字排版和像素对齐，Windows 11 圆角由 DWM 绘制。
- 小字标改善斜线/圆角抗锯齿；主面板随 DPI 选择 ICO 帧，移除最近邻放大。截图、原处翻译及下拉列表补齐渲染设置。
- 手工配置、高级请求配置使用矢量箭头及完整可点击行，展开/收起方向一致。
- 修复标题空白区域不能拖动；设置、关闭按钮保持正常点击。

## 下载与验证

- `Cida-win-x64-preview-Setup.exe`：Windows x64 安装包，可手动升级。
- `Cida-win-x64-preview-Portable.zip`：完整解压，运行根目录 `辞达 Cida（候选版）.exe`。
- `SHA256SUMS.txt`：附件校验。GUI/CLI 自包含，离线简繁中文/英文 OCR 和 VC runtime 随包提供，无需开发证书或 MSIX 身份包。

本机 Release 构建 0 警告、0 错误；Core 96/96，交互 Windows 5/5。真实窗口验证标题连续拖动、拖动后打开设置，以及两个折叠控件；原生/WPF DPI 在当前 100% 桌面一致，主面板已不再分层。详见 `docs/windows-rendering-verification.md`。

当前执行桌面只有一个可检测显示器；完整混合 DPI 多屏、实际 OS 缩放切换、完整 IME、外部应用矩阵、干净机器安装和远端更新尚未验收。没有将受控缩放图片作为实机多屏证明。
