# 辞达 Cida Windows v0.2.0-rc.5（未签名候选版）

修复共用按钮表面的圆角接缝：

- 翻译、摘要、改进、设置、关闭、执行及设置页操作按钮统一修复圆角底色和描边之间的覆盖间隙，保留原圆角大小。

- `Cida-win-x64-preview-Setup.exe`：Windows x64 安装包，可手动升级。

- `SHA256SUMS.txt`：附件校验。GUI/CLI 自包含，离线 OCR 和 VC runtime 随包提供。

浅/深色四档受控栅格的同色圆角接缝检查通过，真实单屏 100% 产品窗口与折叠交互已检查。Core 96/96，Windows 默认测试 4 通过、1 跳过。完整桌面用例因开始前无法安全保存当前用户剪贴板而未通过；没有清空用户剪贴板或修改生产剪贴板逻辑。详见 `docs/windows-control-surface-verification.md`。
