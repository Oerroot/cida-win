# 辞达 Cida Windows v0.2.0-rc.3（未签名候选版）

修复用户反馈的 Windows 界面细节：

- 托盘和设置标题栏使用多尺寸 ICO；小尺寸单独绘制简化字标，按系统尺寸选帧，减少缩放模糊。
- 主面板补回品牌图标；设置、关闭、动作、复制等按钮增加清晰边界与交互状态。
- 模型页文本框、密码框和下拉框统一高度、对齐及内边距；改用细线箭头和匹配字段宽度的弹出列表。
- 托盘右键菜单统一浅深色、字体、图形、间距、分隔线和快捷键提示，保留原生关闭行为。

同时修复 Windows 合成剪贴板文本格式后序号变化导致恢复被拒绝的问题；保留序号和所有者检查。

## 下载

- `Cida-win-x64-preview-Setup.exe`：Windows x64 安装包，可手动升级已有版本。
- `Cida-win-x64-preview-Portable.zip`：完整解压，运行根目录 `辞达 Cida（候选版）.exe`。
- `SHA256SUMS.txt`：附件校验文件。其余 full nupkg、RELEASES 与 JSON 供更新程序使用。

GUI / CLI 为自包含 .NET 10，随包离线简繁中文、英文 OCR 和应用本地 VC runtime。启动不需要开发证书或 MSIX 身份包。配置沿用当前用户目录，既有 tag 与发布附件保留。

## 验证与候选边界

Windows 11 x64 本机 Release 构建 0 警告、0 错误；Core 96/96，交互 Windows 5/5。28 张受控视图图片包含浅深色原生托盘菜单；真实窗口检查标题图标、下拉选择以及托盘“设置”和“退出”。模型表单实测统一 40 DIP、同行 Y 坐标一致。详见仓库 `docs/windows-ui-polish-verification.md`。

Setup 和应用可执行文件无受信任 Authenticode 签名；本版本明确为候选版，不标为正式签名发行版。
