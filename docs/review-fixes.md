# 2026-09-30 评审修复记录

基于 `b4ba904893e54085682e585bff67710f419161f8` 完成修复，分发版本为 `v0.1.3` 预发布。以下区分源码修复、实际运行的自动化验证和未执行的验收；预发布下载不代表正式验收完成。

## 修复范围

| 评审问题 | 当前实现 |
|---|---|
| Bearer 鉴权头 | 使用标准认证头解析，保留认证方案与密钥；覆盖自定义 Basic 认证头 |
| 面板源窗口未赋值 | 显示面板前记录源窗口，每次重新显示都刷新选区；截图结果独立写入输入框 |
| 复制兜底 INPUT 布局 | 补齐原生联合体、指针字段与对齐；x64 大小 40 字节 |
| 整窗快捷键未注册 | 单独注册 Shift 变体并分发独立动作，不再在异步回调查询按键状态 |
| DPI 坐标混用 | HWND 按物理坐标定位；窗口内容保持 WPF DIP；裁剪映射至原图像素并限制边界 |
| 签名私钥进入分发 | 删除项目中的 PFX，加入忽略规则；生成新开发签名证书，私钥不可导出并留在用户证书库；身份包使用文件白名单 |
| 发布 CLI 缺失 | GUI 入口处理命令参数；包内另含 Cida.Cli.exe，适用于终端和管道 |
| 发布依赖系统 .NET | GUI 和 CLI 均以 win-x64 自包含发布，运行时随包携带 |
| 禁用快捷键不持久 | 保存显式 null，保留其与字段缺失的区别 |
| 请求取消与期限无效 | 链接取消令牌覆盖发送、SSE、普通响应和错误响应体；请求期限真正生效 |
| 覆盖层不能还原 | 再按同一快捷键结束覆盖层并返回，同时取消未完成请求 |
| 设置检查关闭窗口 | 保存与关闭分离，检查进度和结果保留在窗口中 |
| UIA 取错控件 | 优先遍历属于源窗口的焦点控件及其祖先，其他元素仅作为选区发现兜底；密码控件禁止复制兜底 |
| 剪贴板格式丢失 | 复制所有可保留格式；无法完整快照时不发 Ctrl+C；恢复在剪贴板锁内检查序号与来源；短暂占用采用有界重试 |
| 输入正文日志 | 移除输入/IME 正文记录及热键诊断文件写入；清理了仍存在的旧热键诊断日志 |

此外，修复了覆盖层更新文本、销毁后继续启动计时器、UIA 刷新与轮询字典并发、批量回复负 id，以及 Velopack 入口位置、目标架构和 PowerShell 5 中文编码问题。

## 剩余边界

自动化桌面验证使用自建 WPF 测试窗口，不能替代 Chrome、Typora、VS Code、管理员窗口等跨应用兼容性验收；不同缩放的裁剪用例为几何验证，混合 DPI 多屏仍需人工确认。完整中文 IME、OCR 用户拖选和长时间运行未重新人工验收。

空运行时目录冒烟不能替代干净机器安装、升级和卸载测试。Setup.exe 尚无正式 Authenticode 签名；身份 MSIX 使用新的开发证书，目标机器必须自行信任相应签名才能注册。构建未导入新的受信任证书、卸载或重新注册用户现有身份包。

当前目录中的私钥文件已删除并更换签名证书，但旧证书信任、历史 Git 提交和旧分发包里的私钥副本没有清理或改写。旧根目录产物不能当作修复版本发布；本轮验证对应 `artifacts/release/0.1.3/`。
