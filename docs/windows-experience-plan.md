## 设计与行为基准

- 800 DIP 主面板、28 DIP 内容边距、14 DIP 外圆角；屏幕工作区限制宽高；输入与结果分别滚动。
- 白色输入与温暖纸色结果，绿色强调；系统浅深色；中文和英文阅读字体随包并保留许可证。
- 来源/动作/请求为快照；编辑标旧，不自动重发；隐藏继续生成；停止保留部分结果；选区复制优先。
- 热键 A/S/D/F 与 Shift+D；输入法组合优先；连接测试和动作预览仅使用草稿。
- 替换前后验证来源、选区、原文与可编辑性；无法证明安全就保留结果。一次来源撤销可恢复。
- OCR 离线兜底无需开发证书；UIA 读操作不在界面线程执行，失效结果不重新贴回窗口。
